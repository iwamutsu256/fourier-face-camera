# Step 4: 仮想カメラへの出力と本番化

## 🎯 目的

実験用だったパラメーターを最適な値で固定し、デバッグ用のUIを取り除いて本番用アプリケーションとして仕上げる。完成した映像を `pyvirtualcam` を利用して仮想カメラへ出力し、ZoomなどのWeb会議ツールで利用可能にする。

## 🧠 学んだこと・技術解説

### プロダクトの「固定」と「チューニング」

実験フェーズでは様々な周波数（Freqs）やエッジ閾値をテストしたが、最終的に周波数を `60` に固定した。
これは、「顔の輪郭などの長い線にはフーリエ変換がかかって滑らかになり、眼鏡や目などの短い線は変換されずにシャープなまま残る」という、アルゴリズムの仕様（入力要素数が周波数より少ない場合はFFTをスキップする）を逆手に取った絶妙なスイートスポットである。

### pyvirtualcam と色空間の変換

OpenCVでレンダリングした `display_frame` はBGR形式の配列であるが、`pyvirtualcam` や一般的な仮想カメラドライバはRGB形式の入力を期待する。そのため、仮想カメラにフレームを `send()` する直前で `cv2.cvtColor(display_frame, cv2.COLOR_BGR2RGB)` による色空間の再反転を行っている。これにより、Web会議上で顔の色（線の色）が「アバターのように真っ青」になるのを防いでいる。

## ⚙️ 実行とWeb会議での利用方法

1. OSに「OBS Studio」がインストールされていることを確認する（仮想デバイスドライバとして必須）。
2. プログラムを実行する。
3. ZoomやGoogle Meetを開き、カメラ設定から `OBS Virtual Camera` を選択する。
4. 自身が滑らかなフーリエアートの線画となって会議に参加できる。
