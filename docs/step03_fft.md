# Step 3: 高速フーリエ変換 (FFT) による線画近似

## 🎯 目的

抽出した顔の輪郭点群に対して離散フーリエ変換を適用し、高周波成分（ノイズや微細な形状）をカットアウトすることで、滑らかで幾何学的な「一筆書き（Fourier Drawing）」の線を生成する。

## 🧠 学んだこと・数学的処理の流れ

### 座標の複素数化とFFT (`np.fft.fft`)

2次元の座標 $(x, y)$ をそのまま扱うのではなく、複素平面上の点 $z = x + iy$ として扱うことで、座標配列を1次元の複素数配列に変換する。これにより、NumPyの強力なFFTアルゴリズムにデータを直接渡すことが可能になる。
FFTを実行すると、空間上の点群が「周波数領域（様々な速度で回転する波の集まり）」へと変換される。

### 高周波成分の除去（ローパスフィルタ）

FFTによって得られた複素係数の配列のうち、配列の中央付近（高周波成分＝細かなガタつき）を `np.zeros_like` を用いて $0$ にリセットする。
配列の先頭（正の低周波）と末尾（負の低周波）だけを残すことで、顔の「大まかな丸みや全体的な形状」というコアな情報だけを抽出できる。

### IFFT (`np.fft.ifft`) による空間への復元

高周波をカットした係数配列に対して逆フーリエ変換 (IFFT) をかけると、周波数領域から再び $(x, y)$ の空間座標へと戻る。この結果として得られる座標群は、数学的に完全に滑らかな曲線（いくつかの円軌道の合成）となる。

## ⚙️ 実行結果と操作

- 赤く細い線：FaceMeshから取得した生の輪郭点群
- シアンの太い線：FFTによって近似・平滑化された線
- `d` キー: 黒背景のアートモードとカメラ映像の切り替え。
- `↑` `↓` キー: フーリエ変換で残す周波数の数（`num_frequencies`）の増減。値を減らすと楕円に近づき、増やすと元の顔の形に近づく。
