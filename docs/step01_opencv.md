# Step 1: OpenCVとNumPyによるWebカメラ映像の取得

## 🎯 目的

プロジェクトのベースとなる、Webカメラからのリアルタイム映像取得パイプラインを構築する。画像データがプログラム内部でどのように表現されているかを理解する。

## 🧠 学んだこと・技術解説

### OpenCVにおける画像データの正体

OpenCV (`cv2.VideoCapture`) で取得した画像フレームは、単なるピクセルの集まりではなく、**NumPyの3次元配列 (`np.ndarray`)** として表現される。

- **データ構造 (`frame.shape`)**: `(高さ, 幅, チャンネル数)` のタプル。例：`(720, 1280, 3)`。
- **データ型 (`frame.dtype`)**: `uint8`（Unsigned Integer 8-bit）。0〜255の整数値で各色の強さを表現する。
- **色空間**: OpenCVはデフォルトで **BGR（青, 緑, 赤）** の順でチャンネルを保持する。一般的なWebや他のライブラリ（MediaPipe等）で使われるRGBとは並び順が異なるため、連携する際は変換 (`cv2.cvtColor`) が必須となる。

### 処理の流れ

1. `cv2.VideoCapture(0)` でOSのデフォルトカメラデバイスを掴む。
2. `while True` ループ内で `cap.read()` を呼び出し、最新のフレーム（配列）を毎フレーム取り出す。
3. `cv2.imshow` で配列データをディスプレイ上のピクセルとしてレンダリングする。
4. `q` キーの入力でループを破棄し、デバイスのロックを解除 (`cap.release()`) する。

## ⚠️ 詰まりやすいポイント

- Mac環境の場合、`cv2.destroyAllWindows()` が即座に反映されずウィンドウがフリーズして残ることがある。対処法として、終了直前に小さなダミー画像を `imshow` するハックを入れている。
